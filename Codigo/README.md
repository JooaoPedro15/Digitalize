# Código do projeto

Esta pasta contém a aplicação Spring Boot do Digitalize.

- `src/main/java/com/digitalize`: backend, organizado por funcionalidade (veja a seção Arquitetura no README da raiz);
- `src/main/resources/db/migration`: migrações do banco (Flyway);
- `src/main/resources/static`: front-end estático servido pelo Spring Boot;
- `src/test`: testes do backend (JUnit) e do painel administrativo (Node).

Para executar e configurar o ambiente, siga o README da raiz.

O protótipo Node/Express das primeiras sprints e o backend original em Spark foram substituídos por esta versão. Eles continuam disponíveis no histórico do git.
